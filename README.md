# Obsidian LLM Skills

Collection de skills [Claude Code](https://claude.com/claude-code) pour **capturer et organiser dans Obsidian** sans friction.

L'esprit : un flux court et cliquable, l'idée/note brute reste intacte, l'IA propose mais ne réécrit jamais à ta place.

## Skills disponibles

| Skill | Rôle |
|-------|------|
| [`idee/`](idee/) | Capter une idée en ~2 min et créer une fiche rangée dans le vault. |

*(D'autres à venir — ex. capture de cours / infos à retenir.)*

## Installation

Chaque skill est autonome. Copie le sous-dossier voulu dans le placard à skills de Claude Code :

```bash
cp -r idee ~/.claude/skills/idee
```

Elle est disponible au démarrage de session suivant. Voir le `README.md` de chaque skill pour la configuration (chemins du vault, etc.).

## Prérequis

- [Claude Code](https://claude.com/claude-code)
- Un vault [Obsidian](https://obsidian.md)
